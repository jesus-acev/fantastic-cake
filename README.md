# Dulce Arte - Web & CMS para Pastelería Artesanal (Nuxt 4)

Monolito web y API de alto rendimiento para pastelería y repostería artesanal, construido con **Nuxt 4**, **Vue 3**, **Nitro**, **TailwindCSS** y **Drizzle ORM** sobre **SQLite**.

---

## 📁 Directorio Principal: `app/`

Aplicación monolítica completa basada en Nuxt, Vue 3, Nitro API y Drizzle ORM sobre SQLite de acuerdo con las especificaciones de `STACK.md`.

- **Puerto Dev**: `http://localhost:3000`
- **Comandos**:
  ```bash
  cd app
  npm install
  npm run dev
  ```
